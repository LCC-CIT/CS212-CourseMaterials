**CS 212, AI Programming 1**

Your project can be an entirely new app that incorporates some type of AI, or you can enhance one of your lab projects with an additional or different AI feature than it originally had. The project should be a stand-alone app  (not a Jupyter notebook). You can use any programming language as long as the app incorporates AI in some way. 

There should be some kind of test driver or unit tests that can be used to verify the program works.

Submit a project proposal before starting on your app.
