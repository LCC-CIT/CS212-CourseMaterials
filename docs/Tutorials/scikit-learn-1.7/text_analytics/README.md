# Text Analytics Exercises

**CS 212 AI Programming 1**

This folder has the starter code for the exercises at the end of the scikit-learn Working With Text Data tutorial:

- **Exercise 1: Language identification.** Train a classifier that uses character n-grams to tell which language a piece of text is written in.
- **Exercise 2: Sentiment analysis.** Train a classifier that decides whether a movie review is positive or negative, using grid search to pick good parameters.
- **Exercise 3: CLI text classification utility.** Combine the models from the first two exercises into a command line program. (There's no skeleton for this one.)

The tutorial page has the full instructions and hints.

## Getting the Data

The datasets aren't included. Download them by running each `fetch_data.py` script from inside its own folder, since the scripts save the data in the current folder. The languages script needs the `lxml` package (`pip install lxml`).

```bash
cd text_analytics/data/languages
python fetch_data.py
cd ../movie_reviews
python fetch_data.py
```

When both scripts have finished, the `data` folder will look like this:

```text
text_analytics/
├── data/
│   ├── languages/
│   │   ├── fetch_data.py
│   │   ├── html/                 # the downloaded Wikipedia pages: ar.html, de.html, ...
│   │   ├── paragraphs/           # one sub-folder per language, one paragraph per file
│   │   │   ├── ar/               #   ar_0000.txt, ar_0001.txt, ...
│   │   │   ├── de/
│   │   │   └── ...               #   en, es, fr, it, ja, nl, pl, pt, ru
│   │   └── short_paragraphs/     # same layout, but each file has only about 5 words
│   │       └── ...               #   (the ja folder is empty)
│   └── movie_reviews/
│       ├── fetch_data.py
│       └── txt_sentoken/
│           ├── neg/              # 1,000 negative reviews, one per file
│           └── pos/              # 1,000 positive reviews, one per file
└── skeletons/
    ├── exercise_01_language_train_model.py
    └── exercise_02_sentiment.py
```

The sub-folder names (`ar`, `de`, `neg`, `pos`, ...) are the category labels that scikit-learn's `load_files` function uses as targets.

## Running the Skeleton Scripts

Each script takes one argument: the path to its training data folder. From the `text_analytics` folder, run:

```bash
python skeletons/exercise_01_language_train_model.py data/languages/paragraphs
python skeletons/exercise_02_sentiment.py data/movie_reviews/txt_sentoken
```

For a harder version of Exercise 1, use `data/languages/short_paragraphs` instead of `data/languages/paragraphs`.

The skeletons won't run without errors until you finish the `# TASK:` steps in them, because the code at the end uses variables (such as `clf` and `y_predicted`) that you have to create. You can also run them in an IDE such as VS Code by setting the data folder path as the script's command line argument.
