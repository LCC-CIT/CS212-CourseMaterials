Folder labels come from breadcrumb_names in _config.yml (the folder name is used if there is no entry). An entry can be a plain label or a name/url pair; a url starting with "/" is from the site root, any other url is relative to that folder. The last item is the page's `breadcrumb` front matter if it has one, otherwise its `title`, otherwise its file name.
