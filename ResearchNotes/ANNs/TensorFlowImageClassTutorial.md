Notes on: <a href="https://www.tensorflow.org/tutorials/keras/classification" target="_blank">Basic image classification</a>

Intro to Keras: <a href="https://www.tensorflow.org/guide/keras" target="_blank">Keras: The high-level API for TensorFlow</a>

Using TF version 2.19.0

Uses this dataset: <a href="https://github.com/zalandoresearch/fashion-mnist" target="_blank">Fashion MNIST</a> dataset which contains 70,000 grayscale images in 10 categories. The images show individual articles of clothing at low resolution (28 by 28 pixels)

The original <a href="https://en.wikipedia.org/wiki/MNIST_database#MNIST" target="_blank">MNIST dataset</a> (Modified National Institute of Standards and Technology database) is a large database of handwritten digits.
